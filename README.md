# Spotify Clone Web Player

A responsive Spotify Web Player UI clone built with semantic HTML5 and custom CSS3.

## Features
- **Sidebar Navigation**: Home, Search, and Library controls
- **Playlist & Podcast Cards**: Interactive cards for trending music and top charts
- **Music Player Bar**: Playback controls, progress bar, album thumbnail, and volume sliders
- **Responsive Layout**: Clean desktop layout mirroring Spotify's signature dark theme

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid)
- FontAwesome Icons
- Google Fonts (Montserrat)

## Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/yashcod21er/<your-repo-name>.git
   ```
2. Open `index.html` in your browser, or launch it with Live Server.
